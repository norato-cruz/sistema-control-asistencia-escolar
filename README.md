#  Sistema de Control de Asistencia Escolar - Liceo Italiano Trilingüe

![C#](https://img.shields.io/badge/Language-C%23-blue)
![IDE](https://img.shields.io/badge/IDE-Visual%20Studio-purple)
![Database](https://img.shields.io/badge/Database-Microsoft%20Access-red)
![License](https://img.shields.io/badge/License-MIT-green)

Aplicación de escritorio desarrollada en **C# (Windows Forms)** conectada a **Microsoft Access** mediante **OLE DB / DataSets / ReportViewer**, orientada a la administración, gestión y reporte de asistencia estudiantil para el Liceo Italiano Trilingüe.

---

##  Características Principales

* 🔐 **Control de Acceso y Roles:** Módulos independientes para **Administrador** y **Maestro**.
* 🗂️ **Gestión Completa de Datos (CRUD):** Control de Años Escolares, Docentes, Grados, Alumnos, Matrículas y Asistencias.
* 🔎 **Centro de Consultas:**
  * Consulta General de asistencias.
  * Auditoría de registros por usuario/docente.
  * Control de usuarios y roles del sistema.
  * Listado de alumnos por grado asignado.
* 📊 **Generación de Reportes:** Reportes parametrizados por fecha, grado e historial mensual de asistencia mediante vistas imprimibles.
* 🛡️ **Validaciones:** Prevención de duplicación de registros de asistencia en la base de datos central.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** C# (.NET Framework)
* **Entorno de Desarrollo:** Microsoft Visual Studio
* **Interfaz de Usuario:** Windows Forms (WinForms)
* **Base de Datos:** Microsoft Access (`.accdb`) mediante OLE DB
* **Reportes:** Microsoft ReportViewer (RDLC)

---

##  Instalación y Requisitos

1. **Requisitos del Sistema:**
   * Sistema Operativo Windows 10 u 11.
   * Microsoft .NET Framework instalado.
   * Motor de base de datos Access (Microsoft Access Database Engine).

2. **Ejecución del Proyecto:**
   * Clona este repositorio o descarga el código fuente ZIP.
   * Abre el archivo de solución `.sln` en **Visual Studio**.
   * Asegúrate de que la cadena de conexión Apunte correctamente al archivo `.accdb` de la base de datos.
   * Compila y ejecuta la aplicación (`F5`).
